## Implementation

.NET 10 Razor Pages with native Azure Table documents and ETag concurrency.
Azure.Identity 1.21.0, Azure.Data.Tables 12.13.0 and Application Insights ASP.NET Core 3.2.0 are pinned.
The current Application Insights SDK uses Entra credential-based export.
Saved Foundry agents are invoked through the documented project Responses endpoint and pinned version references.
No native file-search, contact-center connector, mock production agent or anonymous role selector exists.

## Visual direction

The banking brief calls for a calm service-desk UI: forest-green brand accents, neutral surfaces,
readable tables and restrained spacing. Semantic CSS tokens follow Fluent-style focus, spacing and state
principles without a frontend dependency. Text navigation avoids icon-only controls.
Explicit field labels, skip navigation, visible focus, status/error semantics and overflow-safe tables
support keyboard and narrow screens. No decorative emoji or invented company branding is used.

## Validation and limitations

Desktop/mobile browser screenshots and accessibility checks remain pending before live acceptance.
The public sample is not a production banking interface or compliance certification.
