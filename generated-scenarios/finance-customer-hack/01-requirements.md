### Agentic business workflow

Primary pattern: 04 Routing / Triage; supporting 05 Handoff; selected overlay 17 Human-in-the-Loop.
An application-owned state machine invokes two saved Foundry prompt agents.
This is not a native Foundry workflow or additional Copilot implementation contexts.
A single agent would be simpler but would not meet the explicit multi-agent requirement.

Triage returns typed `Route` = `faq`, `account` or `human`.
It sees the current customer message, not balances, credentials or other customers.
The knowledge specialist receives only fixed bank policies and, for the account route, server-selected own records.
It returns `Answer`, `Sources` and `Escalate`; unknown/empty sources cause human escalation.
Balances are retrieved deterministically and never calculated by the model.
Application code, not the model, enforces identity, role, owner, state and version.
Human routes create a case before acknowledgement. Automated replies stop while that case is human-owned.
Customers can append messages; representatives claim, reply and close. A closed case cannot resume automation.
A new conversation is the explicit fresh automated interaction; no silent handback.

Limits: 1,000 characters per input; 20 persisted messages per case; two agent calls per automated turn;
800 output tokens per call; 45-second per-call and 90-second overall budgets; no automatic inference retries.
Stored case payloads are capped below Azure Table's string-property limit.
Processing reserves the case with an optimistic-concurrency version; stale writes fail, not overwrite.
An interrupted processing turn is explicitly recoverable to the human queue after two minutes.
No full prompts, passwords or hidden reasoning are logged.

### Network security

Authenticated public HTTPS is the confirmed demo assumption.
Data endpoints remain public but require Entra RBAC; service keys and anonymous blobs are disabled.
This deliberately departs from the repository's private-data-endpoint baseline for the confirmed synthetic demo.
No private-only claim, WAF deployment, residency guarantee or production security certification is made.
Private networking would require a separately reviewed operator and automation path, not a silent switch.

### Recommended security controls

Managed identity for all workload Azure calls; separate scenario-scoped deployer grants;
TLS 1.2 minimum; encryption at rest; secure HttpOnly cookies; antiforgery on every write;
salted framework password hashes; five failed logins lock an account for 15 minutes;
per-client login throttling; four-hour nonpersistent sessions; durable revocation stamps;
persistent protected session keys; no public registration or client-selected roles.
